## Чекпойнт 2. Створення акаунтів виключно адміністратором (`js/storage.js`, `js/app.js`, `index.html`)
- [x] **Заборонено самореєстрацію студентів:** Метод `StorageService.authenticateStudent()` більше не створює нові акаунти при вході. Якщо нікнейму немає в реєстрі, система виводить повідомлення про те, що акаунти створює виключно Адміністратор.
- [x] **Усунено витік паролів у формі входу:** При натисканні на швидкий чіп студента (`App.quickSelectStudent()`) заповнюється лише нікнейм — пароль більше не підставляється автоматично, а поле пароля має тип `password` із перемикачем видимості (`👁️`).
- [x] **Видалено резервний PIN-код викладача (`1234`):** У `StorageService.authenticateTeacher()` прибрано обхідний вхід через PIN `1234` (`TCH_MASTER`) — вхід викладача можливий лише за персональним акаунтом, створеним Адміністратором.
- [x] **Розширено керування акаунтами в Адмін-панелі:** Адміністратор може створювати, редагувати, скидати паролі (`🔑 Reset Pass` / `🔑 Edit / Reset`), змінювати аватари та видаляти профілі студентів і викладачів, а також відновлювати метрики при імпорті JSON-бекапу.
